1. Goal
   Develop a data-driven ML model to predict IE (inhibition efficiency) from molecular and operating-condition features, enabling optimization of inhibitor structure and dosage.

2. Problem Definition
   - Input features: C# (carbon number), Mw (molecular weight), HLB (hydrophilic-lipophilic balance), EO (ethylene oxide units), Conc (concentration), pH
   - Target: IE (inhibition efficiency)
   - AA (active agent) is used to rescale IE during preprocessing

3. Data Collection & Understanding
   - ~300 lab samples from corrosion experiments
   - Each sample includes inhibitor formulation (C#, Mw, HLB, EO), test conditions (Conc, pH), and measured IE
   - Three corrosive mediums tested:
     * HCl (Acidic, pH 0.5): 160 samples
     * NaCl (Neutral/Saline, pH 4.9): 74 samples  
     * CPS (Cement Pore Solution, Alkaline, pH 12.5): 61 samples
   
   3a. Medium-Specific Preprocessing (medium_specific_preprocessing.py)
       - Split dataset by corrosive medium (HCl, NaCl, CPS)
       - Apply independent preprocessing to each subset
       - Generate separate train/val/test splits per medium (70/15/15)
       - Outputs in data/processed/medium_specific/{medium}/
       - Purpose: Enable comparison of general vs. medium-specific models

4. Data Preprocessing (preprocessing.py)
   - Load raw dataset, remove non-informative columns
   - Compute IE = IE × AA / 100, then drop AA
   - Drop duplicates and rows with missing IE
   - Split into train/val/test (70/15/15)
   - Fit imputer (mean) and scaler (StandardScaler) on TRAIN only, transform all splits
   - Outputs in data/processed/: train.csv, val.csv, test.csv, cleaned_full.csv
   - Archive: data/archive/dataset_original.csv

5. Exploratory Data Analysis (eda.py)
   - Histograms for all features and IE
   - Pearson correlation heatmap
   - Scatter plots of IE vs key drivers (Conc, pH, HLB, EO)
   - Outputs in data/eda/: histograms.png, correlation_heatmap.png, scatter_plots.png

6. Feature Engineering & Selection (features.py, feature_importance.py)
   - Canonical feature set: C#, Mw, HLB, EO, Conc, pH → IE
   - features.py: loads preprocessed splits, exposes X/y for train/val/test
   - feature_importance.py: baseline importance via linear regression coefficients, RF importances, permutation importance
   - Output: data/feature_importance/baseline_importance.csv

7. Model Selection & Training (train.py)
   - Load preprocessed splits (already imputed + scaled)
   - Tune models on TRAIN using RandomizedSearchCV (3-fold CV, 18 iterations)
   - Evaluate on VAL, pick winner by R²
   - Refit winner on TRAIN+VAL
   - Evaluate on TEST
   - Candidates: RandomForestRegressor, SVR (RBF)
   - Best: RandomForestRegressor (n_estimators=600, max_depth=6, min_samples_leaf=2)
     - Val: R²=0.693, RMSE=20.4
     - Test: R²=0.417, RMSE=20.1
   - Outputs in data/models/: results.json, test_predictions.csv
   
   7a. Medium-Specific Model Training (train_medium_specific.py)
       - Train separate RF and SVR models for each medium
       - Use same hyperparameter tuning strategy per medium
       - Compare performance vs. general model
       - Results (underperformed due to small sample sizes):
         * HCl: Test R²=0.036 (vs. 0.417 general) - 118 samples total
         * NaCl: Test R²=0.204 (vs. 0.417 general) - 118 samples total
         * CPS: Test R²=-0.448 (vs. 0.417 general) - 53 samples total
       - Conclusion: General model benefits from cross-medium learning
       - Outputs in data/models/medium_specific/{medium}/
       
   7b. Feature Importance Analysis (analyze_feature_importance.py)
       - Compare feature importance across mediums
       - Analyze how pH importance varies by environment
       - Generate comparative visualizations
       - Key finding: pH is most important in general model (0.811),
         but drops significantly in medium-specific models where pH is constant
       - Outputs in data/models/medium_specific/feature_importance/

8. Model Evaluation & Interpretation (model_interpretation.py)
   - SHAP analysis: global and local feature importance
   - Partial Dependence Plots: marginal effect of each feature on IE
   - Error Analysis: prediction errors by medium, worst predictions
   - Key findings:
     * pH has highest SHAP importance (18.4), followed by Conc (10.5)
     * CPS medium has highest prediction error (MAE=21.2)
     * Model struggles with extreme IE values
   - Outputs in data/interpretation/

9. Optimization & Design Use-Case (optimize_inhibitor.py)
   - Dosage Optimization: find optimal concentration for surfactants
   - Formulation Recommendation: suggest properties for target IE
   - Sensitivity Analysis: effect of each feature on predicted IE
   - Prediction Reference Table: 90 predictions for common scenarios
   - Key findings:
     * pH has largest effect on IE (71.6% range)
     * Concentration has second largest effect (36.0% range)
     * Model achieves max ~63% IE for NaCl/CPS, ~51% for HCl
   - Outputs in data/optimization/
